3. Applica

Il tabellone cambia da solo entro 3-5 minuti (GitHub deve pubblicare il file, poi il tabellone controlla ogni 2 minuti).

Accesso a GitHub (una volta sola per dispositivo)

Token salvato su questo dispositivo.

Come si crea il token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → chalet_stazione.
  3. Permissions → Repository permissions → Contents: Read and write. Nient'altro.
  4. Scadenza a scelta (quando scade, ne crei uno nuovo). Copia il token e incollalo qui sopra.

Il token resta solo nel browser di questo dispositivo e non viene scritto nel repository. Non condividere questa pagina con il token salvato su un dispositivo non tuo.
